# Vozen Music visual identity

The selected direction combines a vinyl record and a lower V cut, using rounded outlines and the violet, blue, cyan, and cream palette of the Vozen family. No robot or mascot.

- [Avatar](v4/vozen-music-avatar.png)
- [Identity concept board](v4/vozen-music-brandboard.png)

## Proposed implementation colors

| Role | Value |
| --- | --- |
| Background | `#080C17` |
| Violet | `#8247FF` |
| Indigo | `#303FCB` |
| Cyan | `#00CEE6` |
| Cream | `#F5EFDF` |

These are implementation targets, not exact pixel measurements of the textured PNGs. Suggested interface fonts: Manrope and IBM Plex Mono. No font files or vector logo exports are bundled.

Product language is English. The default tagline is **Find your rhythm.** The concept board retains the original Portuguese tagline and includes illustrative interface mockups; these are design references rather than shipped interfaces. Only the final selected raster assets are published here.
